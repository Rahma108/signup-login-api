🔐 Sign Up & Login System (Front-end + Back-end)

This project is my first complete API implementation in Back-end and my first time connecting Front-end with Back-end.

🛠 What I built

I created a Sign Up & Login system where:

Users can create an account (Sign Up)

Users can log in using email and password (Login)

The Front-end communicates with the Back-end through APIs

User data is saved in a JSON file

🧩 Technologies Used
Front-end:

HTML
CSS
JavaScript
Fetch API

Back-end:
Node.js
Express.js
File System (fs)
CORS

How it works

The Front-end sends user data using fetch

The Back-end receives data using Express APIs

Data is validated and saved in users.json

Proper status codes are returned:

201 → Sign Up success

409 → Email already exists

200 → Login success

404 → Invalid login data

🚀Why this project matters

This project represents my starting point in Back-end development, where I learned:

How APIs work

How to connect Front-end with Back-end

How to handle requests & responses

How to store data and validate users
